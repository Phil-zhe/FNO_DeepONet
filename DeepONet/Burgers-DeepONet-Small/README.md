# Burgers-DeepONet-Small

Lightweight PyTorch project for learning the solution operator of the one-dimensional viscous Burgers equation with DeepONet.

## Problem

The PDE is

```text
u_t + u u_x = nu u_xx,   x in [0, 1], t in [0, T]
```

with periodic boundary conditions, `nu = 0.01`, and `T = 1.0`. Initial conditions are random smooth Fourier fields:

```text
u0(x) = sum_{k=1}^K a_k sin(2*pi*k*x) + b_k cos(2*pi*k*x)
```

where `K = 5` and modal amplitudes decay as `1/k^2`.

## Method

Data are generated by a periodic spectral solver:

- FFT derivatives for `u_x` and `u_xx`
- RK4 time stepping with internal stability substeps
- optional 2/3 dealiasing for the nonlinear term

DeepONet learns the operator

```text
G: u0(x) -> u(x,T)
```

The branch net receives sensor values from the initial condition, the trunk net receives query coordinates, and the final prediction is an inner product of branch and trunk latent features.

## Installation

```bash
conda activate MLtorch311_clean
pip install -r requirements.txt
```

No external dataset is needed.

## Generate Data

```bash
python scripts/generate_data.py --config configs/default.yaml
```

Output:

```text
data/processed/burgers_nu0.01_N1000_nx256_nt101.npz
```

The file contains `x`, `t`, `u`, `u0`, `uT`, train/val/test split arrays, and the serialized config.

## Hardware Notes

The default setup is intentionally small for a single NVIDIA RTX 2060 6GB:

- `nx = 256`, `nt = 101`, `total_samples = 1000`
- `n_sensors = 128`, `n_query = 128`
- `hidden_dim = 128`, `latent_dim = 128`
- `batch_size = 32`
- AMP enabled when CUDA is available

If CUDA memory is insufficient, reduce `training.batch_size`, `dataset.n_query`, `model.hidden_dim`, or `model.latent_dim` in `configs/default.yaml`.

## Reproducibility

All key parameters are controlled by `configs/default.yaml`; random seeds are fixed for NumPy and PyTorch. Paths are created automatically and the code runs on Windows, CPU, or CUDA.
